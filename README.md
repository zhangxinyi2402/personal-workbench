# Personal Workbench / 个人工作台

一个用于管理主线目标、年度目标、任务、日程、习惯与个人计划的可配置个人工作台。

## 项目简介

当前版本：**V1**。采用独立静态网页，无需构建、安装依赖或连接后端。打开 index.html 即可使用，也可将本目录内容放在 GitHub Pages 发布根目录。

## 核心功能

- 总览、每日计划、本周视图与月度日历。
- 主线与年度目标、任务与子任务、备忘录、重复任务和习惯打卡。
- 可配置板块、页面布局、主题与自定义背景。
- 本地自动保存、备份导出与恢复。
- 支持响应式 **Desktop / Tablet / Mobile**。

## 数据与隐私

当前数据存储：**Browser LocalStorage**。数据保存在当前浏览器中，不上传到仓库或服务器；默认内容为通用演示示例。

自定义背景由用户在浏览器内上传并存储，本仓库不包含用户背景或个人数据库。请勿把个人导出的任务备份、账号信息或私密内容提交到公开仓库。

不同设备的数据暂未云同步。更换浏览器、清理站点数据或从本地文件切换到 GitHub Pages 地址时，原数据不会自动转移；请通过工作台的数据管理导出和恢复。

## 发布方式

将本目录中的 index.html、README.md 和 .gitignore 上传到所选仓库，随后在 GitHub 中配置 Pages 的发布来源。网页无本地绝对路径、第三方资源或后端服务依赖。
