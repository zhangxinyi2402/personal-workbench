# 我的个人工作台

V1.0 · 一个用于管理主线目标、年度目标、任务、日程、习惯与个人计划的可配置个人工作台。

## 核心功能

- 总览、今天规划、本周共享时间轴、月历与年度目标。
- 所有任务、未分类、已过期筛选，以及批量顺延和撤销。
- 主线与目标管理、主线卡片独立宽高、任务与备忘录、习惯打卡。
- 自定义板块、布局编辑、浅色/深色主题及本地背景图片。
- 支持桌面、平板和手机。

## 运行

本地：直接打开 `index.html` 即可使用，也可用任意静态HTTP服务器预览。不需要构建工具、安装依赖或后端。

GitHub Pages：将本目录内容上传到仓库根目录，在仓库 Settings → Pages 中选择对应分支和根目录。支持站点根路径与仓库子路径；入口是 `index.html`。

## 数据

当前使用浏览器 LocalStorage，数据保存在当前浏览器和站点来源下。发布程序不包含个人浏览器数据库或上传的背景图片。

本地文件与线上网站，以及不同浏览器/域名/协议，不共享存储。迁移个人数据请使用工作台的数据备份与恢复功能；不要把私人备份提交到公开仓库。清除浏览器站点数据会删除本地记录，请定期备份。

当前尚未实现多设备数据同步；下一阶段计划接入云端同步。

发布版本为 V1.0；数据 Schema 版本为6，两者独立。现有用户自定义名称与主题保留，新用户默认名称为“我的个人工作台”，默认使用既有深蓝与金色主题。
